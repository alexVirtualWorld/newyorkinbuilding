# New York in Building

An interactive 3D exploration project built with [three.js](https://threejs.org/), WebGPURenderer, and TSL, forked from [mrdoob/slop-newyork](https://github.com/mrdoob/slop-newyork).

This project transforms the urban architecture of Manhattan into enterable structures with realistic and logical floor layouts. Players can seamlessly enter buildings directly from the street, explore detailed interiors, and navigate across multiple floors.

[Try it live](https://alexvirtualworld.github.io/newyorkinbuilding/)

## Key Features

* **Enterable Manhattan Architecture:** Step off the streets of New York and walk directly into surrounding buildings.
* **Logical Floor Layouts:** Structured interior spaces featuring distinct rooms, connecting corridors, walls, doors, and furniture.
* **Vertical Navigation:** Functional stairs and elevators connecting different levels of the buildings for multi-floor exploration.

## Getting Started

1. Clone this repository:

   git clone [https://github.com/alexVirtualWorld/newyorkinbuilding.git](https://github.com/alexVirtualWorld/newyorkinbuilding.git)

2. Serve the project directory using a local web server (e.g., VS Code Live Server, `npx serve`, or `python -m http.server`) and open `index.html` in a WebGPU-supported browser.
